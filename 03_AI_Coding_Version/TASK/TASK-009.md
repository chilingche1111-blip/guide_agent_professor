# TASK-009 沉浸式校园首页

## 用户要求

从单框交互转向沉浸式动态网页，参考网上实例；保留原智能体能力，更新报告和截图，不做Coze。

## 实现

- 原首页迁移到 `static/workbench.html`，根路径建立独立沉浸体验。
- `campus-world.js` 原创程序化校园，真实Three.js渲染、射线拾取、拖动旋转、缩放、镜头聚焦、昼夜灯光、连续动态和暂停。
- `campus.js` 对接知识API、原文手册、目的地资料与侧边问答；保留原工作台API与配置入口。
- 免费依赖和许可证本地保存，不复制参考站素材。
- 无三维渲染时回退到知识/服务导航；系统减少动画默认暂停，后台和屏幕外停止连续渲染。
