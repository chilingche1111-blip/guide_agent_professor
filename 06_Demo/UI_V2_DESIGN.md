# 校伴 V2 界面说明

设计依据：UI/UX Pro Max 的响应式、可访问性与交互规范，结合参考案例中的历史会话、知识管理、来源展示和模型设置。没有直接照搬参考案例的登录、支付或心理评估模块。

视觉方向：面向大学生的安静工作台。鼠尾草绿表达校园与可靠感，纸面背景降低长时间阅读刺激；系统中文无衬线承担正文，少量宋体用于首页“答案”二字。原创线描校园 SVG 不依赖外部图库或字体网络。

布局：244px 左侧工作导航；中央单一主任务；证据侧栏按需打开。手机导航折叠，不把所有功能挤进聊天框。首页三个建议卡片只填充问题，不在用户阅读前自动触发可能付费的模型请求。

交互：Enter 发送、Shift+Enter 换行，兼容中文输入法组合；原生 dialog 处理焦点与 Escape；可见键盘焦点、跳转主内容、状态 aria-live、减少动画；控件图标统一 SVG。已检索与已引用分开，模拟业务与真实服务分开，联网摘要与模型生成分开。

截图为真实浏览器渲染：`screenshots/v2/`。测试宽度为 375、768、1024、1440；另测试深色模式、移动导航和弹窗关闭。没有声称完成全量屏幕阅读器或所有设备认证。

旧 `UI_DESIGN_DECISIONS.md` 与旧截图是 V1 设计证据，保留供对照，不再作为当前界面说明。
