# 校园卡补办

## 丢卡后的处理
上海交通大学校园卡遗失后，应先挂失，再补领卡片。

## 预约及取卡
可通过交我办App中的校园卡自助办卡服务预约，持六位预约码在自助机领取，不需要校园卡密码。页面列出的取卡点包括闵行及徐汇网络信息中心、闵行学生中心大楼。

也可直接在自助机选择补办，通过学工号及卡密码、身份证及卡密码，或交我办扫码完成身份验证。此摘要不执行真实补卡，办理以来源页面为准。
