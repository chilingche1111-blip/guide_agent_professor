# 查询校园卡余额与消费明细

## 手机与网页查询
上海交通大学用户可在交我办App的信息服务中查看我的校园卡。PC版既可从个人信息资源中的卡码资源进入，也可从信息服务的校园卡查询入口进入。

## 自助设备查询
校内补卡机、餐厅圈存机也提供查询途径。自助设备位于闵行网络信息中心、学生中心大楼和徐汇网络信息中心等位置。本助手不能读取真实账户余额或个人消费明细。
