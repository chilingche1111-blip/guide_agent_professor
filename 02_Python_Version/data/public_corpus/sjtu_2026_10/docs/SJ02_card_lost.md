# 校园卡挂失与解挂

## 线上途径
在上海交通大学交我办PC版，可进入信息服务下的校园卡查询和挂失服务。手机端可在交我办App的信息服务中打开我的校园卡，办理挂失或解挂。

## 线下途径
挂失也可在校内自助设备办理，包括闵行网络信息中心和学生中心、徐汇网络信息中心的自助机，以及餐厅圈存机。本文只提供指引，不代替持卡人进行身份验证或实际挂失。
