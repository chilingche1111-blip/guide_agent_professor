# 交大VPN与校外资源访问

## 对象及开通
上海交通大学为在校学生及教职工提供访问校内资源的免费VPN服务。申请jAccount后自动开通，VPN用户名与该账号一致。

## 使用注意
官方页面提供客户端及操作系统配置指引。服务限制并发连接，建议使用结束后断开，避免影响之后连接。应只从学校官方入口获取安装说明和客户端，不向本助手提供账号密码。页面混有新旧平台说明，具体系统配置须打开原网页核对。
