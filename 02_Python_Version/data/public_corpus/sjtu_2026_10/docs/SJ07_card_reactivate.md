# 找回旧校园卡后的激活

## 有效身份与单卡规则
上海交通大学旧卡对应的在校身份仍有效时，可在自助机激活旧卡。同一时期只能有一张有效校园卡，激活旧卡会使已补办的新卡立即失效。

## 操作途径
在自助机选择旧卡激活，使用账户信息或交我办扫码验证，按提示将旧卡放到读卡区并确认激活。是否执行应由本人决定，本助手不能替代身份验证。
