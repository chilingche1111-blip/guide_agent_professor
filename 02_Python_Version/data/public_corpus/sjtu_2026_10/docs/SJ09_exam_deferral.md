# 本科生缓考申请

## 申请与证明
上海交通大学本科生原则上应在考试前通过教学信息服务网提交缓考申请并附证明。因突发疾病申请时，病假证明需来自校医院或二级甲等以上医院，并覆盖考试时段。

## 审批与特殊情况
院系教学秘书审核后由教务处审批。确因突发事件不能提前办理时，应在考试期间报告辅导员或教学秘书并获批准，由其在考试结束前报教务处代办。通过审批后原则上不能撤销。通选课、重修免修考及过程性考试不在适用范围；其余条件请核对原办法。
