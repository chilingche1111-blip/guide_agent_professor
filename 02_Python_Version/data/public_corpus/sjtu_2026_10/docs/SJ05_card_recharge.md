# 校园卡充值

## 充值途径
上海交通大学官方介绍交我办App、支付宝校园一卡通服务及校内现金充值点三种途径。支付宝需要选择对应学校，再填写持卡信息。

## 余额同步与时间限制
在线充值后，需要在食堂支持实体卡的消费机具刷卡同步金额，刷卡同步本身不必消费。页面提醒每日23:00至次日05:00不要充值。本系统不收款、不代充，不请求银行卡信息。
