# 图书馆开放与借阅指南

## 开放时间
采集时上海交通大学图书馆新生指南列出通常开放时段为每天08:00至22:30。节假日及特殊情况另有安排，应查看图书馆官网、官方微信公众号或现场通知，不能将常规时间当作节假日保证。

## 借阅及预约
页面对计划内学生列出普通外借周期30天、续借周期30天；册数和续借次数列为不限。预约图书到达后在预约架保留一周，通知可在交我办消息或我的图书馆查看。具体资源例外与当前执行情况以馆方规定为准。
