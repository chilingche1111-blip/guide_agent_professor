# 校园卡免密消费限额

## 默认限额
上海交通大学页面说明，校园卡免输密码消费按每个餐段累计计算，默认上限是30元，而不是每笔交易30元。

## 调整方式
持卡人可以带校园卡到校内自助设备调整消费限额。摘要不推断未在该页面列出的可设最高金额或其他学校的规则。
