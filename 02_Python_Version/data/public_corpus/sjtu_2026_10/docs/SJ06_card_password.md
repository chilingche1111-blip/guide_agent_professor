# 忘记校园卡密码

## 重置流程
上海交通大学持卡人可到自助终端选择修改密码，使用交我办App扫描设备二维码完成身份验证，再设置并确认六位新密码。先修改的是查询密码；修改消费密码还需要按设备提示放卡操作。

## 适用边界
该扫码流程不适用于校友卡和不记名消费卡等类型。无法自助重置时，可带校园卡及身份证件到网络信息中心处理。请在官方设备操作，不向聊天助手提供证件号或密码。
