# 长安大学信网处服务联系电话

网络运维服务中心受理有线网、无线网等问题，联系电话 029-82334701、029-82334702。校园卡管理中心联系电话为 029-62630098、029-62805236。

统一身份认证、服务门户、一网通办及邮箱可咨询信息技术部 029-82334716、029-82334703，邮箱 xxzyb@chd.edu.cn。在线教学、课程录制等业务可咨询教育技术部 029-82334343。
网页与信网处常见问题对南校区部分服务窗口的楼层、方位表述不一致，因此本摘要不提供确定导航，请先电话核实。本地模拟人工工单不会拨打这些号码或通知学校人员。
