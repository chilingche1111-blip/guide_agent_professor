# 长安大学图书馆校外数据库访问
校内用户在校园网外需要访问图书馆数据库时，可从 https://vpn.chd.edu.cn/ 进入学校VPN服务。图书馆该问答给出的网络服务咨询电话为 029-82334701。
该来源未给出图书借阅册数、借期或当日开放时间，不能据此回答这些规则。旧版详细说明链接可能失效，应从图书馆或信网处当前主页核实。VPN入口存在不等于已获全部数据库访问权限。
