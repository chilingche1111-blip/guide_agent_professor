# 长安大学VPN系统使用指南
## 校外访问校内资源
访问 https://vpn.chd.edu.cn/ 后使用统一身份认证登录。在网页端选择图书馆或业务直通车，可访问相应校内资源。该指南说明网页访问图书馆不需安装插件；远程服务器、正版软件激活和校园云盘等场景可能需要VPN客户端。
## 客户端与帮助
客户端应从学校VPN页面获取，服务器地址按指南设置为 vpn.chd.edu.cn。登录异常可查看 https://vpn.chd.edu.cn/com/help/ 或咨询信息技术部 029-82334716。此处只提供操作指引，不代登录或收集校园账号密码。
