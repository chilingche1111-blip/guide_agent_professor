# 长安大学正版软件获取与激活
## 获取渠道
在校学生和教职工可通过学校正版软件平台 http://ms.chd.edu.cn/，或服务门户的“业务直通车—软件正版化”入口，使用统一身份认证获取授权范围内的软件。官方页面列出Windows、Office、MATLAB及MathType，具体可用版本以平台为准。
## 校外激活与咨询
激活需校园网环境；校外应先按学校指引连接VPN客户端。平台提供的软件授权不是任意软件的永久授权，也不能据此激活不在许可范围内的家庭版。办理前备份个人数据，不在本助手运行激活工具；服务咨询电话为 029-82334705。
