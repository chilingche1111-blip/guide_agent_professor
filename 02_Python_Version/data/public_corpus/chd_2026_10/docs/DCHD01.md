# 长安大学统一身份认证与校园卡常见问题
## 统一身份认证
首次使用统一身份认证需激活账号，登录账号为学号或工号，密码由本人设置。应绑定手机和邮箱，便于找回密码。无法自助找回时联系信息技术部 029-82334716；不要在本助手提交密码、证件照片或验证码。
## 校园卡挂失与电子卡
校园卡新办、挂失、补办请咨询校园卡管理中心：南校区 029-62630098，北校区 029-62805236。微信或支付宝搜索“长安大学校园卡”小程序，以统一身份认证登录电子校园卡。不同官方页面的南校区窗口位置有差异，请先电话核实，不据此摘要导航。
## 校园网自助服务
网络自助服务平台 https://wlfw.chd.edu.cn:8800/ 支持开户、缴费、套餐变更和账号管理，使用统一身份认证。校园网问题可咨询 029-82334701。
