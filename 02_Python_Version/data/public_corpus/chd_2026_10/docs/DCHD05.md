# 长安大学研究生证明与学籍业务
## 成绩单与在读证明
2022年通知说明，研究生中英文成绩单、在读证明及奖学金证明可持校园卡或通过信息门户账号在自助打印机办理。其他需用印的证明先经学院审核，再提交研究生院线下办理。具体设备位置和当前流程应向研究生院核实。
## 学籍异动
通知中的休学、复学、出国留学等业务可通过研究生系统申请，经导师、培养学院、研究生院逐级审批；退学、转导师等特殊业务需线下沟通。该规定仅针对研究生，不能作为本科生学籍流程依据。本助手不提交申请或查询真实审批记录。
