## 数据质量与隔离

- 不复制网页全文，不以不同摘要文件重复同一网页凑数量。
- 信网处常见问题与联系方式对南校区服务位置表述不一致，摘要保留冲突提示，不输出确定导航。
- 图书馆旧版开放时间、借阅规则等页面本次访问返回404，不采用搜索摘要中的旧时间作为现行规定。
- 研究生规定不外推本科生；没有查到的流程应明确未知。
- 原12份模拟文档与用户上传属于 `simulation`，不混入官方范围。上海交大示例与其测评结果是历史实验，不进入在线检索。
- 每个会话只使用一种资料范围。切换时前端新建会话，后端拒绝跨范围复用；旧会话仍按模拟范围恢复。
